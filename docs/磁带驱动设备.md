# 磁带驱动设备

磁带设备在Linux系统中是字符设备，对应多种文件名：

- SCSI磁带设备使用名称 `/dev/st0`、`/dev/nst0`、`/dev/st1`、`/dev/nst1` 等。SCSI磁带接口和驱动被广泛认为是最可靠的，但SCSI磁带驱动器成本较高。
- ATAPI磁带设备从 `/dev/ht0` 和 `/dev/nht0` 开始命名。
- 软盘控制器上的磁带驱动器支持有限，对应 `/dev/ft0` 和 `/dev/ntf0`。

识别磁带设备时，可在内核日志中查找如下行：

```shell
Vendor: HP     Model: C1533A         Rev: 9503
Type: Sequential-Access            ANSI SCSI revision: 02
st: Version 20010812, bufsize 32768, wrt 30720, max init. bufs 4, s/g segs 16
Attached scsi tape st0 at scsi0, channel 0, id 4, lun 0
```

## 磁带设备类型

Unix系统上的磁带设备有两种版本：

- **倒带设备**：每次操作后自动倒带，例如 `/dev/st0`。
- **非倒带设备**：操作后不自动倒带，名称以 `n` 开头，例如 `/dev/nst0`。

日常操作中，倒带设备几乎无用。后续章节将说明如何调整磁带位置。

## mt命令操作

常用命令示例：

```shell
# 查看状态
mt -f /dev/nst0 status

# 倒带
mt rewind

# 前进到下一个文件
mt fsf

# 后退到上一个文件
mt bsf
```

## 创建与读取存档

创建三个存档的步骤：

1. 插入新磁带，设置 `TAPE=/dev/nst0`。
2. 使用 `tar zcv lib` 存档/lib目录。
3. 重复操作存档/boot和/dev目录。

## 直接文件访问

使用 `dd` 直接读写磁带（需指定块大小）：

```shell
# 从磁带读取tar存档（块大小10KB）
dd bs=10k if=/dev/nst0 of=output.tar
```

## 常见归档程序块大小

| 程序 | 块大小  | dd参数 |
| ---- | ------- | ------ |
| tar  | 10KB    | bs=10k |
| cpio | 512字节 | bs=512 |
| dump | 10KB    | bs=10k |
